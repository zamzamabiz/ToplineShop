## 1. Objective

Implement the complete authentication session lifecycle for ToplineShop backend:
- Global `JwtAuthGuard` with `@Public()` allowlist decorator
- `POST /auth/login`, `POST /auth/logout`, `POST /auth/refresh` endpoints
- Refresh token rotation with HMAC-SHA256 digest (raw token never stored)
- Replay revocation: reused refresh token revokes ALL active sessions for user
- Write endpoint protection: `POST /tenants`, `POST /vendors`, `POST /categories`, `POST /products` require authentication
- Public GET endpoints remain accessible without auth
- Rate limiting on auth endpoints via `@nestjs/throttler@6.5.0`

## 3. Files Created

### `backend/src/auth/decorators/public.decorator.ts`
```typescript
import { SetMetadata } from '@nestjs/common';
export const IS_PUBLIC_KEY = 'isPublic';
export const Public = () => SetMetadata(IS_PUBLIC_KEY, true);
```
Global allowlist decorator. Applied to all GET routes and auth endpoints (login, refresh).

### `backend/src/auth/types/jwt-payload.type.ts`
JWT access token claims: `sub`, `tenantId`, `roles`, `jti`, `iat`, `exp`.
`AuthenticatedUser` interface attached to `request.user` after guard passes.

### `backend/src/auth/dto/login.dto.ts`
`LoginDto`: `email` (IsEmail), `password` (IsString, IsNotEmpty), `tenantId` (IsString, IsOptional).

### `backend/src/auth/dto/refresh.dto.ts`
`RefreshDto`: `refreshToken` (IsString, IsNotEmpty).

### `backend/src/auth/strategies/jwt.strategy.ts`
`JwtStrategy extends PassportStrategy(Strategy)`:
- Extracts JWT from `Authorization: Bearer <token>` header
- Validates `jti` claim by looking up session in database
- Rejects if session is revoked or expired
- Returns `AuthenticatedUser` object attached to `request.user`

### `backend/src/auth/guards/jwt-auth.guard.ts`
`JwtAuthGuard extends AuthGuard('jwt')`:
- Registered globally via `APP_GUARD` token in `AuthModule`
- Checks `IS_PUBLIC_KEY` metadata; allows through if `@Public()` is set
- Calls `super.canActivate()` for non-public routes
- `handleRequest()` throws `UnauthorizedException('Authentication required')` for no/invalid user

### `backend/src/auth/auth.service.ts`
Key behaviors:
- **login**: argon2id password verification, creates Session row, issues access + refresh tokens, writes audit event
- **logout**: revokes session by `revokedAt`, writes audit event
- **refresh**: validates token via HMAC lookup, rotates (revoke old + create new session), writes audit event
- **Constant-time guard**: calls `argon2.hash(password)` even when user not found (timing attack prevention)
- **Replay detection**: if refresh token already revoked → `updateMany` revokes ALL user sessions
- **HMAC**: `createHmac('sha256', JWT_REFRESH_SECRET).update(raw).digest('hex')` — raw token returned to client, hash stored in DB

### `backend/src/auth/auth.controller.ts`
```
POST /auth/login    @Public() @Throttle({ default: { ttl: 60000, limit: 5 } })
POST /auth/refresh  @Public() @Throttle({ default: { ttl: 60000, limit: 30 } })
POST /auth/logout   (requires auth)
```

### `backend/src/auth/auth.module.ts`

## 5. TypeScript Errors Fixed

### TS2353 — `argon2.verify()` does not accept `{ type }` option
`argon2.verify()` auto-detects algorithm from the hash string. The `type` option only applies to `argon2.hash()`. Removed `{ type: argon2.argon2id }` from `verify()` call.

### TS2416 — `handleRequest` signature mismatch
Changed signature from `(err: unknown, user: unknown)` to `(err: any, user: any): any` to match `IAuthGuard` base interface.

### ESM compatibility — `@nestjs/jwt@12.0.2` and `@nestjs/passport@12.0.0` are pure ESM
Both packages have `"type": "module"` with no CJS entry point. Jest's CJS environment throws `SyntaxError: Cannot use import statement outside a module`.

**Resolution**: Added `jest.mock('@nestjs/jwt', factory)` and `jest.mock('@nestjs/passport', factory)` at the top of `auth.spec.ts`. Jest hoists these calls above all `import` statements, replacing the ESM packages with CJS-compatible implementations before any import chain loads them. Production runtime is unaffected (mocks only apply within Jest).

The `@nestjs/passport` mock's `AuthGuard()` base class checks for `Authorization` header and throws `UnauthorizedException` when absent, matching the real Passport JWT reject behavior and ensuring HTTP tests 12–15 (POST without token → 401) pass correctly.
