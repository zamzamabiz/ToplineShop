### 4.3 `Session` model — new (P8-002 sole owner)

Added at the end of `backend/prisma/schema.prisma`:

```prisma
model Session {
  id        String    @id @default(uuid())
  userId    String    @map("user_id")
  tenantId  String    @map("tenant_id")
  tokenHash String    @unique @map("token_hash")
  ipAddress String?   @map("ip_address")
  userAgent String?   @map("user_agent")
  expiresAt DateTime  @map("expires_at")
  revokedAt DateTime? @map("revoked_at")
  createdAt DateTime  @default(now())

  user   User   @relation(fields: [userId], references: [id])
  tenant Tenant @relation(fields: [tenantId], references: [id])

  @@index([userId])
  @@index([tenantId])
  @@index([expiresAt])
  @@map("sessions")
}
```

**Field design rationale:**

| Field | Type | Rationale |
|---|---|---|
| `id` | `String @id @default(uuid())` | Consistent with all existing models |
| `userId` | `String @map("user_id")` | Required FK to `users.id`; every session belongs to a user |
| `tenantId` | `String @map("tenant_id")` | Required FK to `tenants.id`; sessions are tenant-scoped |
| `tokenHash` | `String @unique @map("token_hash")` | Digest of the refresh token (not the raw token); `@unique` enables O(1) lookup and prevents duplicates; raw token is never stored |
| `ipAddress` | `String? @map("ip_address")` | Nullable — IP at session creation; used for compromise detection |
| `userAgent` | `String? @map("user_agent")` | Nullable — UA at session creation; used for compromise detection |
| `expiresAt` | `DateTime @map("expires_at")` | Required — absolute session expiry; indexed for cleanup queries |
| `revokedAt` | `DateTime? @map("revoked_at")` | Null = active; non-null = revoked; enables soft-revocation without deleting the audit trail |
| `createdAt` | `DateTime @default(now())` | Session creation time; consistent with existing convention (no `@map` on `createdAt`) |

**Indexes:**

- `@unique` on `tokenHash` — unique constraint creates a B-tree index; enables lookup by token digest in O(log n)
- `@@index([userId])` — session listing per user
- `@@index([tenantId])` — session listing per tenant
- `@@index([expiresAt])` — expiry-based cleanup/revocation queries

**Relations:**

- `user User @relation(fields: [userId], references: [id])` — `ON DELETE RESTRICT ON UPDATE CASCADE`
- `tenant Tenant @relation(fields: [tenantId], references: [id])` — `ON DELETE RESTRICT ON UPDATE CASCADE`
- Back-references added to `User` (`sessions Session[]`) and `Tenant` (`sessions Session[]`)

**Security note:** `tokenHash` stores a digest of the refresh token. P8-003 must decide the exact hashing scheme (HMAC-SHA256 is recommended for high-entropy random tokens per the Phase 8 readiness plan §F; Argon2id is overkill for high-entropy tokens). The column is `TEXT` to accommodate any hash format. P8-002 does not implement the hashing logic — that is a P8-003 deliverable.
