## IMPLEMENTATION

### 1. Logging Interceptor

Created `backend/src/common/interceptors/logging.interceptor.ts`:
- Records: method, path, status, duration, correlation ID, user agent
- Generates UUID correlation ID if not provided via `X-Correlation-ID` header
- Returns correlation ID in response headers
- Structured JSON logging format
- Sanitizes user agent (truncates long values)
- Logs successful and failed requests

### 2. Bootstrap Integration

Updated `backend/src/main.ts`:
- Added `LoggingInterceptor` to global interceptors
- Added `X-Correlation-ID` to CORS allowed headers
- Configured NestJS logger to use `['error', 'warn', 'log']` levels
