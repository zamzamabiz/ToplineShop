## OBJECTIVE

Resolve and verify the API connectivity failure discovered during the P7-002 WDR audit. The frontend defaulted to port 3001 while the backend listens on port 4000; the frontend environment variable name also differed from the client code.

## FAILURE EVIDENCE (BEFORE)

| Issue | Source | Value |
|-------|--------|-------|
| Frontend default port | `src/lib/api-client.ts:15` | `http://localhost:3001` |
| Backend port | `backend/src/main.ts:15` | `4000` |
| Frontend env var (code) | `src/lib/api-client.ts:14` | `NEXT_PUBLIC_API_URL` |
| Frontend env var (.env.example) | `.env.example:7` | `NEXT_PUBLIC_API_BASE_URL` |
| Backend CORS | `backend/src/main.ts` | Not configured |

## ROOT CAUSE

1. **Port mismatch**: Frontend defaulted to 3001, backend listens on 4000
2. **Variable name mismatch**: Code used `NEXT_PUBLIC_API_URL`, .env.example used `NEXT_PUBLIC_API_BASE_URL`
3. **Missing CORS**: Backend had no CORS configuration for cross-origin requests from frontend

## CORRECTIVE ACTIONS

### 1. Frontend API Client

Updated `src/lib/api-client.ts`:
- Changed default URL from `http://localhost:3001` to `http://localhost:4000`

### 2. Frontend Environment Example

Updated `.env.example`:
- Changed `NEXT_PUBLIC_API_BASE_URL` to `NEXT_PUBLIC_API_URL`
- Changed value from `http://localhost:3001` to `http://localhost:4000`

### 3. Backend CORS Configuration

Updated `backend/src/main.ts`:
- Added `app.enableCors()` with environment-driven allowed origins
- Default: `http://localhost:3000`
- Configurable via `CORS_ALLOWED_ORIGINS` env var (comma-separated)
