## OBJECTIVE

Remove the possibility of sensitive query data entering request logs. Preserve useful route observability while logging only a safe pathname.

## ISSUES IDENTIFIED (BEFORE)

| Issue | Location | Problem |
|-------|----------|---------|
| Raw `request.url` logged | `logging.interceptor.ts:44` | `url` field contained full URL with query strings |
| Raw `request.url` logged | `all-exceptions.filter.ts:92` | `url: request.url` contained full URL with query strings |

## CORRECTIVE ACTIONS

### 1. Logging Interceptor

Updated `backend/src/common/interceptors/logging.interceptor.ts`:
- Added `getSafePath()` method that extracts pathname only (no query strings)
- Changed `url` field to `path` field in log output
- Query strings completely excluded from logs

### 2. Exception Filter

Updated `backend/src/common/filters/all-exceptions.filter.ts`:
- Added `getSafePath()` method that extracts pathname only (no query strings)
- Changed `url` field to `path` field in log output
- Query strings completely excluded from logs
