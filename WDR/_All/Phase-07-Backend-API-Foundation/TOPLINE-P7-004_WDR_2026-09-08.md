## IMPLEMENTATION

### 1. CreateTenantDto

Created `backend/src/tenants/dto/create-tenant.dto.ts`:
- `name`: required string, 1–255 chars
- `slug`: required string, 1–255 chars, lowercase letters/numbers/hyphens only
- `type`: must be one of `PLATFORM` or `VENDOR`
- `status`: must be one of `ACTIVE` or `SUSPENDED`

### 2. TenantsService.create()

Added to `backend/src/tenants/tenants.service.ts`:
- Checks for existing tenant with same slug
- Returns `ConflictException` if slug exists
- Creates tenant with validated input
- Returns safe `TenantSummaryDto` (no secrets, no raw fields)

### 3. TenantsController

Updated `backend/src/tenants/tenants.controller.ts`:
- Added `POST /tenants` endpoint
- Returns HTTP 201 Created on success
- Uses `CreateTenantDto` with global `CustomValidationPipe`
- No raw exception details exposed
