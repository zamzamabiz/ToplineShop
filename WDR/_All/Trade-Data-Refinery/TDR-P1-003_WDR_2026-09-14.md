## 9. Batch Detail Behavior

**Mock detail derivation** (no new mock data added to `mockData.ts`):
All detail data is computed inside `TdrBatchDetailPanel.tsx` from existing `TdrBatch` fields:

- **File type / Submitted by**: deterministic lookup by `batch.sourceName`
- **Warning / Error / Fatal split**: proportional distribution of `batch.quarantineCount` per `batch.status`
- **Published count**: `acceptedCount` for ACCEPTED; 70% of `acceptedCount` for PARTIAL; 0 for FAILED
- **Quality score**: `(acceptedCount / (acceptedCount + quarantineCount)) × 100`, rounded to 1 dp
- **Checkpoints**: static per `batch.status` (QUEUED/PROCESSING/ACCEPTED/PARTIAL/FAILED)
- **Issues**: synthetic count list scaled to `quarantineCount` per `batch.status`

**State-aware checkpoint display:**
| Status | Checkpoint outcome |
|---|---|
| QUEUED | File received ✓, rest pending |
| PROCESSING | Received ✓, schema ✓, mapping ✓, validation pending |
| ACCEPTED | All done ✓ (quarantine row: ⚠ if quarantine > 0) |
| PARTIAL | Received/schema ✓, mapping ⚠, validation ⚠, quarantine ⚠, publish disabled |
| FAILED | Received/schema ✓, mapping ✗, validation ✗, quarantine ✗, publish disabled |
