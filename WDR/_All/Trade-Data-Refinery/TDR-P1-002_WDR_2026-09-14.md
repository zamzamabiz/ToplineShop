## 9. Filter / Search / Pagination Behavior

- **Search:** case-insensitive substring match on `sourceName` + `status`. Live (no submit needed).
- **Status filter:** exact `TdrBatchStatus` match.
- **Source filter:** exact `sourceName` match. Source options derived from current `batches` prop via `useMemo`, so they update per scenario.
- **Page size:** resets page to 1 on change. Default 5.
- **Pagination:** `safePage = Math.min(page, totalPages)` prevents out-of-range page after filter reduces result count.
- **Clear filters:** resets `search`, `statusFilter`, `sourceFilter`, `page` to defaults.
- **Filter state isolation:** `key={viewState}` in page.tsx causes `TdrBatchTable` to remount when the scenario dropdown changes, cleanly resetting all filter state.
