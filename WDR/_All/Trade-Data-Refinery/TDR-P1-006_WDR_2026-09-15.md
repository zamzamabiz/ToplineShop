## 8. UX Features Implemented

### Configure Sources Preview Button
- Added to `TdrSourceHealthPanel` below the source list, visible when `sources.length > 0`.
- Hidden when no sources exist (empty/no-imports scenario).
- Label: "Configure Sources Preview" with `Settings2` icon.
- `aria-expanded` attribute set correctly.
- Full-width button matching TDR visual language.

### Source Configuration Portal Modal
- Portal via `createPortal(…, document.body)` — same pattern as `TdrBatchDetailPanel` and `TdrQuarantineReviewPanel`.
- `role="dialog"`, `aria-modal="true"`, `aria-labelledby="tdr-src-cfg-title"`.
- Escape key closes modal.
- Focus lands on close button on open.
- Backdrop click closes modal.

### Synthetic Source Configuration Data
Four source configs keyed by source name, derived from existing `TdrSourceHealth` entries:

| Source | Config State | Type | Schedule |
|---|---|---|---|
| Global Trade Registry | Ready | JSON Feed | Daily |
| Asia-Pacific Customs API | Ready | REST API | Hourly |
| EU Trade Data Feed | Needs Review | CSV Import | Weekly |
| Americas Logistics Index | Draft | SFTP Drop | Weekly |

Each config includes: sourceType, dataDomain, ownerTeam, dataFormat, schedule, expectedColumnsCount, mappingProfile, validationProfile, quarantineRule, ingestionMode, retentionNote, notes.

### Status Filter
- Filter buttons: All · Active · Paused · Attention
- `aria-pressed` on each filter button.
- Active filter highlighted with brand color.

### Search
- Text input with search icon, `aria-label`.
- Searches across: source name, source type, owner team, data domain, mapping profile.
- Case-insensitive.

### Empty Filtered State
- When no sources match: "No sources match the current filters."
- "Reset filters" action link clears search and status filter.

### Selected Source Detail
- Click a source in the list → detail panel updates (local React state only, no API call).
- Identity block: source ID, type, data domain, owner team, last seen, batch count.
- Read-only configuration form (10 fields): display name, connection type, format, schedule, expected columns, mapping profile, validation profile, quarantine rule, ingestion mode, owner team — all rendered as read-only styled divs labelled "planned only".
- Retention note block.
- Notes block.
- Production safety note.

### Disabled Future Actions (6 buttons)
All buttons have `disabled` attribute, `aria-disabled="true"`, and `title` explaining the requirement:
1. Save Configuration
2. Test Connection
3. Pause Source
4. Resume Source
5. Run Sample Validation
6. Start Ingestion

Section labelled "Source Actions — Backend / Auth required".

### Preview-Only / Production Safety Notes
- Amber warning banner: "Synthetic configuration data only — no credentials are stored, no connectors are tested, no ingestion is started."
- Detail area: "Real source connection testing must happen server-side. Credentials must never be stored in the browser."
- Footer: "Preview only — no configuration is saved or applied."
