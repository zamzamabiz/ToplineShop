## 8. UX Features Implemented

### TDR Project Metrics Button
- Visible on main `/tdr` dashboard, positioned between page header and preview state selector.
- Labelled "TDR Project Metrics" with a `BarChart3` icon.
- Uses native `<button type="button">` with `aria-expanded` attribute.
- Chevron direction indicates open/closed state.

### Expandable/Collapsible Panel
- Click button → panel opens with full metrics.
- Click button again or X (close) button in panel header → panel collapses.
- Keyboard operable via native button elements and focus-visible ring.
- `aria-expanded` on toggle button; `role="region"` with `aria-label` on panel.
- `aria-controls` links button to panel id.

### Preview-Only Warning Banner
