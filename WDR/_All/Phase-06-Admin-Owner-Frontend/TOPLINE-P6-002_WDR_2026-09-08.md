```typescript
{
  ok: true,
  data: T,
  meta?: { count?: number, phase?: string }
}
```

### Standard Error Response
```typescript
{
  ok: false,
  error: { code: string, message: string }
}
```

## API CLIENT FEATURES

1. **Configurable base URL** — `NEXT_PUBLIC_API_URL` env var, fallback `http://localhost:3001`
2. **JSON headers** — Content-Type: application/json
3. **Error handling** — HTTP errors, API error responses, network failures
4. **URL encoding** — Proper encoding of path parameters
5. **Query string builder** — For product filters (tenantId, vendorId, categoryId, status)
6. **No write methods** — GET only
7. **No auth logic** — No headers, tokens, or RBAC
