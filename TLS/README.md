# TLS Master Project

This folder holds module planning and team handoffs within the existing ToplineShop repository. It is not a replacement application root or a second repository.

## Modules

- [ERP64 Master Strategy](ERP64/README.md): platform strategy, execution system, module portfolio, and reusable governance templates.
- [Trade Refinery](Trade%20Refinery/README.md): trade intelligence and data refinery strategy, frontend-first delivery, and parallel-team handoff.

The canonical project dashboard remains governed by `src/project/projectRegistry.ts`. Module documents do not independently authorize implementation or change registry status.
