# Chohan product imagery

This folder contains the local editorial images used by the Chohan Industries Products page.

- Keep images grouped by the product catalog naming convention: `<parent-category>-<child-category>.jpg`.
- Store the approved local asset path in the catalog record rather than linking directly to an external image host.
- Keep meaningful alt text beside every image reference in the catalog data.
- Replace images through the admin media workflow when the media library is connected; do not edit public URLs in production by hand.
